# Ideas para este fork

Ideas sacadas de revisar los forks de [tandpfun/wardrobe](https://github.com/tandpfun/wardrobe) con cambios propios (35 de 340, revisados el 2026-11-15). Entre paréntesis está el fork donde aparece cada idea, para dar crédito y revisar su código si la tomamos.

Marca `[x]` cuando una idea quede hecha en este fork.

## Prioridad (top 5)

- [ ] **Pestaña de Outfits**, generando looks a partir de una prenda y con "mejor ocasión de uso"
- [ ] **Foto modelada solo cuando la pidas** + **registro de gastos** de la API
- [ ] **Filtros** del clóset y **editar prendas** después de importarlas
- [ ] **"Qué comprar después"**: cuántos outfits nuevos desbloquea cada prenda
- [ ] **App en español**

## Hecho

- [x] Calidad de imagen seleccionable (baja / media / alta) al importar y regenerar, baja por defecto

## Descartado por ahora

Cosas que otros forks hicieron pero no encajan con un uso personal y local:

- Multiusuario con cuentas, planes de cobro y panel de administrador
- Subir la app a servidores (Vercel, Railway, Cloudflare, Convex)

## Antes de tomar código de otro fork

- Revisar que siga con licencia MIT.
- Dar crédito en el README (sección "Changes in this fork") y en el commit.
- Hacerlo en una rama propia por idea.
